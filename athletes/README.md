# 契約選手の毎月の見直し（毎月11日）

対象：`対象ブランド.txt` のブランド（約50）。**サッカー選手・フットサル選手だけ、1ブランド最大5人。**

## 流れ（下書き → 内海さんの確認 → 反映）

1. **11日（定期タスク）**：各ブランドの契約選手を調べ、変更案を2つのファイルに書く
   - `proposals/YYYY-MM.json` … 反映用のデータ（形は `scripts/apply_athletes.py` の説明を参照）
   - `proposals/YYYY-MM.md` … 確認用。ブランドごとに「追加・継続・削除」と理由、出典URL
   - サイトのデータ（`src/content/brands/`）には**まだ触らない**
2. **内海さんが確認**：md を見て OK／差し戻しを伝える
3. **反映**：OK が出たら
   ```
   python3 scripts/apply_athletes.py athletes/proposals/YYYY-MM.json
   npm run build
   git add -A && git commit -m "契約選手をYYYY-MM時点に更新"
   ```

## 選手を載せる基準

- **出典で契約が確認できる選手だけ。** ブランドの公式発表、選手・クラブの公式発表、信頼できる報道（ESPN、BBC、The Athletic、Footy Headlines、SoccerBible、各国の主要紙など）
- 「着用している」だけでは契約とみなさない（スパイクの自腹購入やクラブの供給契約の可能性がある）。**個人契約の記事があるもの**に限る
- 代表的な選手から最大5人。現役を優先し、引退した選手は「生涯契約」でも外す
- 名前はカタカナ（日本での一般的な表記）。国は代表国（例：フランス）
- 移籍・契約終了の報道があれば削除する。分からなくなった選手は残さず外す（「不確かな情報は書かない」）
- 出典の記事の日付が古い（2年以上前）選手は、継続しているかを確認してから残す
