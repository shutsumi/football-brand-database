# サッカーブランド図鑑（フォルダ名は旧称のスポーツブランド図鑑）

世界のサッカーブランドを紹介する静的サイト（Astro）。個人名は出さない一般向け。
**対象は「サッカー用品をひとつでも作っているブランド」。** 主力がサッカーでなくてもよい。
**見せたいのは「どこの国のブランドか」と「いつ創業か」。** 売上は扱わない。超マイナーブランドを知れることに価値を置く。

```
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/ に出力
```

## ブランドを追加する

1. ロゴを Wikimedia Commons から `public/logos/<id>.svg` に保存する（ファイルページのURL・ライセンス・作者を控える）。Commons に無ければロゴは書かない（ブランド名の文字で代用表示される）
2. `src/content/brands/<id>.md` を作る。ファイル名がURLになる（`nike.md` → `/brands/nike/`）。項目は既存の `nike.md` を写す。
   創業年・創業者・名前の由来・ロゴ・グループは、確認できなければ省略してよい
3. 持ち主の会社を `src/content/groups/<id>.md` に作り、ブランド側の `group:` にそのIDを書く。独立系のブランドも会社を1グループとして作る。
   まだページの無い傘下ブランドは、グループ側の `otherBrands` に名前だけ書く
4. 国・競技は `src/lib/taxonomy.ts` にあるIDだけ使える。足りなければそこに追加する
5. `npm run build` が通ればOK（項目の抜けやIDの誤りはビルドで落ちる）

## データのルール

- **出典URLを必ず残す。** `sources` に記事・公式ページ、契約選手は1人ずつ `source` に契約を報じた記事
- **確認できないことは書かない。** 「〜とされる」で済ませず、出典で裏が取れない記述は削る
- 契約選手は移籍・契約終了が起きやすい。生涯契約など長期の裏付けがある選手を優先し、直したら `updated` を更新する
- ロゴは商標。フッターの商標表記は消さない

## 一括取り込み（2026-10-04、112件）

- 候補は英語版Wikipediaの「Category:Sportswear brands」と、Wikidataでサッカーチームの「kit supplier（P5995）」になっているブランド
- 記事本文でサッカー用品（ユニフォーム・スパイク・ボール・GKグローブ）を作った・供給したと確認できたものだけ採用。小売店・OEM・他競技だけのものは除外
- 国・創業年・日本語名・公式サイト・ロゴは Wikidata から取得。欠けていた分と、Wikidataと本文が食い違った分は Wikipedia の本文・情報欄で確定させた
- 創業年の値が割れているもの・見つからないものは空欄（「創業年不明」と表示）
- `country` は今の本拠地、創業国が違えば `origin` に書く（例：Athleta は日本、創業国はブラジル）
- 親会社（グループ）は Wikidata だと過去の所有者が混ざるため、一括では入れていない

## 売上高（グループページだけ）

トップからは外した。グループページ（`/groups/`）には Nike・adidas・ASICS の売上高が残っている。円換算は `src/lib/fx.ts` の ECB 参照レート。
